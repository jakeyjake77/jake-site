# jake-site

Personal site built with Astro. Notes go in `src/content/notes/`, essays in `src/content/essays/`. Math uses KaTeX (`$inline$`, `$$display$$`).

Run locally:

```
npm install
npm run dev
```

Then open http://localhost:4321/jake-site/

Pushing to `main` deploys to https://jakeyjake77.github.io/jake-site/
